# Star 1 Kannada
Next.js App Router, TypeScript and Tailwind CSS 4. Responsive English/Kannada homepage.

Run `npm install` and `npm run dev`. Production: `npm run build` (static export in `out/`).

The login/signup forms are UI previews only; no credentials are saved or transmitted. Connect a production identity provider before enabling accounts. Event dates and programmes are clearly marked illustrative. Add confirmed schedules, official contacts and partner identities before launch.

`public/logo.png` is the supplied logo. `public/banner.png` was generated with the built-in image generation tool.
Banner prompt: Wide cinematic photographic website banner for a Kannada news and cultural events channel, Mysore Palace illuminated at blue hour, warm golden lights, burgundy and gold festive atmosphere, subtle crowd silhouettes, editorial architectural photography, 16:9, no text, logos or watermarks.

The six-card event carousel moves left automatically and supports pause/play, arrow controls, touch scrolling and reduced-motion preferences. Hovering or focusing the carousel pauses it. The Donate dialog previews preset amounts only; no payment provider is connected. The six partner wordmarks are fictional sample identities, explicitly labelled on the page.
